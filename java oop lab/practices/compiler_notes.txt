CSC241 - Lab 02 - COMPILER NOTES (Task 3)

ATTEMPT 1 - overload that differs only by return type
Added to OverloadDemo.java:

    int enroll(String courseCode) {
        return 1;
    }

Command : javac OverloadDemo.java
Message :

OverloadDemo.java:26: error: method enroll(String) is already defined in class OverloadDemo
    int enroll(String courseCode) {
        ^
1 error

Reason: the method signature is only the name plus the parameter list, so
enroll(String) and enroll(String) are the same signature. The return type is
not part of the signature, and at a call site such as enroll("CSC241") the
compiler would have no information to choose between the two. Fix: the method
was commented out.

STRETCH QUESTION
If show(long) and show(double) both exist, the call show(10) selects
show(long). The literal 10 is an int, and widening to long is preferred over
widening to double because long is the narrower of the two applicable types.
